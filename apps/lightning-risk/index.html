Reference and use limitations

Annex L is informational. A result below a tolerable-risk value does not certify an installation and does not waive mandatory requirements for special occupancies, project specifications or AHJ decisions.

NFPA 780-2026 basis: NG is obtained from the supplied 2020 Figure L.2 and converted once by NSG = 1.7 × NG; all occurrence-frequency equations use NSG; the near-structure collection boundary uses 350 m; NM is not permitted to be negative.
